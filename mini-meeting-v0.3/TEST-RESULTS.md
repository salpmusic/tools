# v0.3 検証結果

実施日: 2026-11-13 (UTC)

## 合格した検証

- トークン発行の7グループの自動テスト: 実 SDK による JWT 署名と検証、会議限定の権限、ランダムな参加者ID、最大5分の有効期間、会議期限による短縮、10人上限のルーム作成設定。
- 不正コード・未知の会議・期限切れ・不正 Origin・不正メソッド・不正パス・過大入力・不正JSON・名前の制御文字・短すぎるコードの拒否。
- 発行回数制限、未設定時の拒否、LiveKit API エラー時に秘密情報を応答しないこと。
- Wrangler 4.50.0 の `deploy --dry-run`: ビルド成功、Rate Limit binding を認識。
- Playwright Chromium 151 / WebKit 26.5 (Linux) の画面テスト: 入退室、マイク/カメラ切替、発話者表示・固定解除、表示対象だけの映像受信、音声優先、再接続表示、認証拒否、接続失敗、マイク拒否時の聞くだけ参加、音声再生ボタン、認証情報をストレージへ保存しないこと。
- 映像トラックの取り付け・切替時の解除、音声トラックの重複取り付け防止と解除。
- 両ブラウザで公式 LiveKit Client 2.24.0 の実ファイル読み込み、HTML の SRI 検証と `isBrowserSupported()` を確認。
- CDN ファイルが公式 npm 配布物と一致することを確認。
- 390px 幅の画面で横スクロールがないことを確認。
- JavaScript 構文チェック。
- `npm audit --omit=dev`: 報告された既知の脆弱性0件。

ブラウザ検証のための追加ライブラリは `/tmp` にだけ展開し、リポジトリやシステム設定には追加していません。

## まだ確認していないこと

- LiveKit Cloud を通した音声・映像の送受信。実プロジェクトの Secret とトークン発行サーバーURLが未設定です。
- iPhone / Windows / 古い iPad の実機動作、カメラ・マイク使用表示の消灯、スピーカーの音質、実際の通信断からの復帰。
- 10人同時接続の実機性能と、11人目の実サーバーでの拒否。

UI テストは SDK テストダブル、Server テストはルーム作成APIの差し替えを使用しています。実 SDK の読み込みテストは接続・通話テストではありません。設定完了後に README の2台テストを実施してください。
