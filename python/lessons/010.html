第10回：リストのインデックスとスライス ～BASICの配列と比べてみよう～

※TIOBE Index 2026年10月

目標

  • 正の番号と負の番号を使って、リストから値を取り出せるようになる。
  • スライスを使って、リストの一部分を取り出せるようになる。
  • 開始・終了の番号を省略する書き方を覚える。

BASICとの比較

BASICでは、配列の要素を A(1) のように番号で指定します。Pythonでは、リストの要素を a[0] のように角かっこで指定します。

Pythonのリストは、先頭から数えるだけでなく、末尾から数えることもできます。

操作BASICPython
先頭の値A(1) ※a[0]
3番目の値A(3) ※a[2]
最後の値配列の末尾番号を指定a[-1]
一部分を取り出すFOR文などで順番に取り出すa[1:4]

※ BASICは方言や配列の宣言方法によって、番号が0から始まる場合もあります。ここでは1から始まる配列を例にしています。

Pythonの便利な機能が「スライス」です。a[開始:終了] と書くだけで、連続する複数の値をまとめて取り出せます。

コード

# 第10回：リストのインデックスとスライス

fruits = ["りんご", "みかん", "バナナ", "ぶどう", "もも"]

# 正のインデックス（先頭は0）
print("先頭:", fruits[0])
print("3番目:", fruits[2])

# 負のインデックス（末尾は-1）
print("最後:", fruits[-1])
print("後ろから2番目:", fruits[-2])

# スライス（終了位置は含まない）
print("1番目から3番目:", fruits[0:3])
print("2番目から4番目:", fruits[1:4])

# 開始・終了の省略
print("先頭から3個:", fruits[:3])
print("3番目から最後:", fruits[2:])
print("全部:", fruits[:])

# スライスの結果は新しいリスト
part = fruits[1:3]
print("取り出したリスト:", part)

実行結果の例

先頭: りんご
3番目: バナナ
最後: もも
後ろから2番目: ぶどう
1番目から3番目: ['りんご', 'みかん', 'バナナ']
2番目から4番目: ['みかん', 'バナナ', 'ぶどう']
先頭から3個: ['りんご', 'みかん', 'バナナ']
3番目から最後: ['バナナ', 'ぶどう', 'もも']
全部: ['りんご', 'みかん', 'バナナ', 'ぶどう', 'もも']
取り出したリスト: ['みかん', 'バナナ']

ポイント

  • 正のインデックス：先頭が 0、次が 1 です。a[2] は3番目の値になります。
  • 負のインデックス：a[-1] は最後、a[-2] は後ろから2番目です。末尾から数えたいときに便利です。
  • スライス：a[1:4] はインデックス 1、2、3 の値を取り出します。終了位置の 4 は含みません。
  • 省略形：a[:3] は先頭から3個、a[2:] は3番目から最後まで、a[:] は全部を取り出します。
  • 新しいリスト：スライスの結果は新しいリストになります。元のリストは変わりません。1個だけ番号で取り出す場合とは違います。

ミニ課題

次のリストがあります。

colors = ["赤", "青", "緑", "黄", "白"]

このリストから、スライスを使って「青」「緑」「黄」の3つを取り出し、print() で表示してみましょう。

ヒント：最初に取り出したい「青」のインデックスは 1 です。終了位置は含まれないことに注意しましょう。

答え例

# 答え
colors = ["赤", "青", "緑", "黄", "白"]

print(colors[1:4])
▶ このコードをブラウザLinuxで実行

実行結果：

['青', '緑', '黄']

colors[1:4] は、インデックス1から3までの3つの値を取り出します。4 の位置にある「白」は含まれません。
