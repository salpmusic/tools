第15回：デフォルト引数とキーワード引数 ～省略できる引数と名前付きで渡す～

※TIOBE Index 2026年10月

目標

  • デフォルト引数を使って、引数を省略できる関数を作る。
  • キーワード引数を使って、引数の名前を指定して値を渡す。
  • 2つの仕組みを組み合わせて、使いやすい関数を作る。

BASICとの比較

第14回では、関数に値を渡す「引数」と、計算結果を返す「戻り値」を学びました。今回は、その引数をもっと便利に使う方法を学びます。

例えば、挨拶を作る関数を考えてみましょう。BASICでは、名前と語尾の両方を毎回渡すことが多いです。

BASICのイメージ：

10 NAME$ = "Mika" : ENDING$ = "!"
20 GOSUB 100
30 PRINT MSG$
40 END
100 MSG$ = "Hello, " + NAME$ + ENDING$
110 RETURN

語尾をいつも "!" にするなら、毎回書くのは少し手間です。Pythonでは、よく使う値をデフォルト引数として最初から決めておけます。

def greet(name, ending="!"):
    return f"Hello, {name}{ending}"

これなら、語尾を省略しても "!" が使われます。さらに、引数の名前を指定して渡す（キーワード引数）こともできます。

値を渡す変数に入れてから GOSUBgreet("Mika", "!")
よく使う値を省略種類によって異なるending="!" のデフォルト引数
名前を指定して渡す種類によって異なるgreet(name="Mika")
結果をもらう決まった変数return ...

コード

# 第15回：デフォルト引数とキーワード引数

# 1. デフォルト引数
# ending を省略すると "!" が使われる
def greet(name, ending="!"):
    return f"Hello, {name}{ending}"


print("1. デフォルト引数")
print(greet("Mika"))
print(greet("Ken", "."))
print(greet("Yuki", "!!"))


# 2. キーワード引数
# 引数の名前を指定して値を渡す
def introduce(name, city):
    return f"{name} lives in {city}."


print()
print("2. キーワード引数")
# 普通は定義した順番で渡す
print(introduce("Mika", "Tokyo"))
# 名前を指定すれば順番を入れ替えられる
print(introduce(city="Osaka", name="Ken"))


# 3. デフォルト引数とキーワード引数
# tax_rate の初期値は 0.10（10%）
def total_price(price, tax_rate=0.10):
    total = price * (1 + tax_rate)
    return round(total)


print()
print("3. 税込み価格")
print("1000円 → " + str(total_price(1000)) + "円")
print("1000円 → " + str(total_price(1000, 0.08)) + "円")
print("2000円 → " + str(total_price(2000, tax_rate=0.08)) + "円")


# 4. 位置引数とキーワード引数の組み合わせ
print()
print("4. 引数の組み合わせ")
print(greet("Hana", ending="♪"))
print(greet("Taro"))

ポイント

  • デフォルト引数は、引数に初期値を設定する仕組みです。ending を省略すると、自動的に "!" が使われます。
  • デフォルト値は、別の値で上書きできます。例：greet("Ken", ".") → Hello, Ken.
  • キーワード引数は、引数の名前を指定して値を渡す書き方です。例：introduce(name="Mika", city="Tokyo")
  • キーワード引数を使えば、順番を入れ替えられます。例：introduce(city="Osaka", name="Ken")
  • 位置引数とキーワード引数を組み合わせることもできます。例：greet("Hana", ending="♪")。位置引数は、キーワード引数より前に書きます。
  • デフォルト値のない引数は、デフォルト値のある引数より前に定義します。def greet(ending="!", name): はエラーになります。
  • 税率など、よく使う数値をデフォルト値にすると便利です。total_price(1000) だけで税込み10%になります。
  • round() は数値を丸める関数です。今回の金額計算は学習用の例です。

ミニ課題

数と割引率を受け取り、割引後の価格を整数で返す関数 discount_price を作ってください。discount のデフォルト値は 0.10（10%引き）にします。discount_price(1000) と discount_price(1000, 0.20) と、キーワード引数で discount_price(discount=0.20, price=2000) を表示してください。

ヒント：割引後は price * (1 - discount) です。round() で整数にしてから返しましょう。

答え例

# 答え
def discount_price(price, discount=0.10):
    return round(price * (1 - discount))


print(discount_price(1000))
print(discount_price(1000, 0.20))
print(discount_price(discount=0.20, price=2000))
