BASICとの比較

今回は、普通の辞書をもう一歩便利に使ってみましょう。

BASICでは、名前と点数を別々の配列に入れて管理する方法があります。

例えば、次のようなイメージです。

10 DIM N$(2), S(2)
20 N$(1)="太郎": S(1)=80
30 N$(2)="花子": S(2)=90
40 FOR I=1 TO 2
50 PRINT N$(I), S(I)
60 NEXT I

Pythonの辞書なら、名前と点数をキーと値の組み合わせで管理できます。

やりたいことBASICの考え方Pythonの辞書
名前と点数を管理配列を組み合わせる{"太郎": 80}
名前を一覧表示名前の配列をループkeys()
点数を一覧表示点数の配列をループvalues()
名前と点数を表示同じ番号で取り出すitems()
見つからない名前に対応条件分岐などで確認get()

Pythonでは、辞書に用意された便利な機能を使うことで、短くわかりやすく書けます。

コード

# 第18回：辞書をもう一歩
# items・get・更新と削除、関数と組み合わせる

# 1. 辞書の復習
print("1. 辞書の復習")

scores = {"太郎": 80, "花子": 90, "三郎": 75}

print(scores)
print("太郎の点数:", scores["太郎"])

# 2. keys()・values()・items()
print("\n2. 辞書の一覧表示")

print("名前の一覧")
for name in scores.keys():
    print(name)

print("点数の一覧")
for score in scores.values():
    print(score)

print("名前と点数の一覧")
for name, score in scores.items():
    print(name, ":", score, "点")

# 3. get() で安全に取り出す
print("\n3. get() で取り出す")

print("花子:", scores.get("花子", 0))
print("四郎:", scores.get("四郎", 0))

# 4. 辞書を更新する
print("\n4. 辞書の更新")

scores["太郎"] = 85
scores.update({"花子": 95, "四郎": 70})

print(scores)

# 5. 辞書から削除する
print("\n5. 辞書の削除")

removed = scores.pop("三郎", None)
print("削除した点数:", removed)
print(scores)

# 6. 辞書を関数に渡す
print("\n6. 辞書を関数に渡す")

def show_scores(data):
    for name, score in data.items():
        print(f"{name}さんは{score}点です")

show_scores(scores)

# 7. 関数から辞書を返す
print("\n7. 関数から辞書を返す")

def make_student(name, score):
    return {"名前": name, "点数": score}

student = make_student("五郎", 88)
print(student)
print(student.get("名前", "不明"))

ポイント

1. keys()・values()・items() の違い

辞書には、中身を順番に取り出すための便利な機能があります。

  • keys()：キーだけを取り出す。
  • values()：値だけを取り出す。
  • items()：キーと値をセットで取り出す。

特に items() はよく使います。

for name, score in scores.items():
    print(name, score)
▶ このコードを実行（軽量版） 🐧 PC向け Linux Lite

name にキー、score に値が入ります。

Python 3.7.3では、辞書の要素は追加した順番で取り出されます。

2. get() は見つからないキーにも対応できる

普通の scores["四郎"] は、キーが存在しないと KeyError になります。

一方、次のように書けば安全です。

scores.get("四郎", 0)
▶ このコードを実行（軽量版） 🐧 PC向け Linux Lite

「四郎」がなければ、代わりに 0 を返します。

第17回の kwargs.get() も、同じ辞書の機能でした。

なお、get() は辞書の中身を変更しません。

3. update() でまとめて更新できる

scores.update({"太郎": 85, "花子": 95})
▶ このコードを実行（軽量版） 🐧 PC向け Linux Lite

複数のキーと値をまとめて設定できます。

すでにあるキーなら値を更新し、ないキーなら新しく追加します。

第12回で学んだ scores["太郎"] = 85 と同じ更新を、まとめて行えるわけです。

4. pop() で削除しながら値を取り出せる

removed = scores.pop("三郎", None)
▶ このコードを実行（軽量版） 🐧 PC向け Linux Lite

「三郎」があれば、その項目を削除して点数を返します。

なければ None を返すので、エラーになりません。

None は「値がない」ことを表す特別な値です。

削除だけなら、次の書き方もあります。

del scores["三郎"]

ただし、del はキーが存在しないとエラーになるため注意しましょう。

5. 辞書は関数と組み合わせられる

辞書を関数の引数として渡せます。

def show_scores(data):
    for name, score in data.items():
        print(name, score)

また、関数の中で辞書を作り、return で返すこともできます。

def make_student(name, score):
    return {"名前": name, "点数": score}

複数の情報をひとまとめにして返したいときに便利です。

ミニ課題

問題1：辞書の中身を一覧表示

次の辞書があります。

prices = {"りんご": 120, "みかん": 80, "バナナ": 150}

items() を使って、商品名と値段を順番に表示してください。

ヒント：for name, price in prices.items(): を使います。

問題2：安全に取り出して更新

問題1の辞書を使います。

  1. get() で「ぶどう」の値段を調べ、なければ 0 を表示する。
  2. update() で「りんご」を130円に変更し、「ぶどう」を200円で追加する。
  3. pop() で「みかん」を削除する。

ヒント：update() には、変更したいキーと値をまとめた辞書を渡します。

問題3：辞書を返す関数

名前と年齢を受け取り、次のような辞書を返す make_person() 関数を作ってください。

{"名前": "太郎", "年齢": 20}

ヒント：第14回で学んだ return を使います。

答え例

# 問題1
prices = {"りんご": 120, "みかん": 80, "バナナ": 150}

for name, price in prices.items():
    print(name, price, "円")

# 問題2
print("ぶどう:", prices.get("ぶどう", 0))

prices.update({"りんご": 130, "ぶどう": 200})
prices.pop("みかん", None)

print(prices)

# 問題3
def make_person(name, age):
    return {"名前": name, "年齢": age}

person = make_person("太郎", 20)
print(person)
