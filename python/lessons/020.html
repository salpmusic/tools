第20回：データの並べ替え ～sortedとsortで順番を整理する～

※TIOBE Index 2026年10月

目標

  • sorted() を使って、元のリストを変えずに並べ替えられる。
  • sort() を使って、元のリストを直接並べ替えられる。
  • 辞書のリストを、点数や価格などの値を基準に並べ替えられる。

BASICとの比較

第19回では、リストの中に辞書を入れて、複数の情報をまとめて管理する方法を学びました。

今回は、そのデータを小さい順や大きい順に並べ替えてみましょう。

例えば、生徒の点数を低い順に並べたいとします。

BASICでは、隣り合う数値を比較して、順番が違っていたら入れ替える方法があります。

次の例は、その考え方を示したBASIC風のコードです。

10 DIM A(3)
20 A(1)=80: A(2)=95: A(3)=70
30 FOR I=1 TO 2
40 FOR J=1 TO 3-I
50 IF A(J)>A(J+1) THEN SWAP A(J),A(J+1)
60 NEXT J
70 NEXT I
80 FOR I=1 TO 3
90 PRINT A(I)
100 NEXT I

Pythonでは、こうした並べ替えの処理を自分で書かなくても、sorted() や sort() が使えます。

やりたいことBASICの考え方Python
小さい順に並べる比較して入れ替えるsorted()
大きい順に並べる比較の向きを変えるreverse=True
元の配列を並べ替える配列の中身を入れ替えるsort()
元の順番を残す別の配列にコピーするsorted()
点数を基準に並べる点数を比較するkey= で指定する

Pythonなら、数値だけでなく、辞書に入っている点数や価格を基準にして並べ替えることもできます。

コード

# 第20回：データの並べ替え
# sortedとsortで順番を整理する

# 1. sorted() で小さい順に並べる
print("1. sorted() で並べ替え")

scores = [80, 95, 70, 85]

new_scores = sorted(scores)

print("元のリスト:", scores)
print("並べ替え後:", new_scores)

# 2. 大きい順に並べる
print("\n2. 大きい順に並べる")

high_scores = sorted(scores, reverse=True)

print("大きい順:", high_scores)
print("元のリスト:", scores)

# 3. sort() で元のリストを並べ替える
print("\n3. sort() で並べ替え")

numbers = [5, 2, 8, 1, 4]

print("並べ替え前:", numbers)

numbers.sort()

print("並べ替え後:", numbers)

numbers.sort(reverse=True)

print("大きい順:", numbers)

# 4. 文字列を並べ替える
print("\n4. 文字列の並べ替え")

fruits = ["orange", "apple", "banana"]

print("元のリスト:", fruits)
print("アルファベット順:", sorted(fruits))

# 5. 辞書のリストを点数順に並べる
print("\n5. 辞書のリストを並べる")

students = [
    {"名前": "太郎", "点数": 80},
    {"名前": "花子", "点数": 95},
    {"名前": "三郎", "点数": 70}
]

def get_score(student):
    return student["点数"]

sorted_students = sorted(students, key=get_score)

print("点数の低い順")
for student in sorted_students:
    print(student["名前"], student["点数"], "点")

# 6. 点数の高い順に並べる
print("\n6. 点数の高い順")

ranking = sorted(students, key=get_score, reverse=True)

for student in ranking:
    print(student["名前"], student["点数"], "点")

# 7. 元の順番を確認する
print("\n7. 元の順番を確認")

for student in students:
    print(student["名前"], student["点数"], "点")

ポイント

1. sorted() は新しいリストを作る

sorted() は、並べ替えた結果を新しいリストとして返します。

new_scores = sorted(scores)

元の scores は変更されません。

元の順番を残しておきたいときに便利です。

2. sort() は元のリストを変更する

sort() は、リストそのものを並べ替えます。

numbers.sort()

並べ替えた結果は、そのまま numbers に入っています。

sort() の戻り値は None です。

そのため、次のようには書きません。

new_numbers = numbers.sort()

これでは new_numbers に並べ替えたリストではなく、None が入ってしまいます。

比較sorted()sort()
元のリスト変わらない変わる
結果新しいリストを返す戻り値はNone
使い方sorted(data)data.sort()
向いている場面元の順番を残す元の順番を変更する

3. reverse=True で大きい順にできる

普通は小さい順に並びます。

大きい順にしたいときは、reverse=True を指定します。

sorted(scores, reverse=True)

sort() でも同じように使えます。

scores.sort(reverse=True)

4. key= で並べ替えの基準を指定する

第19回で学んだ、辞書を入れたリストを考えてみましょう。

students = [
    {"名前": "太郎", "点数": 80},
    {"名前": "花子", "点数": 95}
]

このデータは、辞書そのものを直接比較して並べることはできません。

そこで、どの値を使って並べるかを key= で指定します。

def get_score(student):
    return student["点数"]

この関数は、生徒の辞書から点数だけを返します。

sorted(students, key=get_score)

Pythonは、各生徒の点数を取り出して、その値を基準に並べ替えます。

ここで get_score() と括弧を付けず、get_score と書くことがポイントです。

関数をその場で実行するのではなく、並べ替えのためにPythonへ渡しています。

5. 点数の高い順なら reverse=True を追加する

sorted(students, key=get_score, reverse=True)

key= と reverse=True は一緒に使えます。

これで、点数の高い生徒から順番に並びます。

同じ点数の生徒が複数いる場合は、元のリストで先にいた生徒が先に並びます。

6. 文字列も並べ替えられる

sorted(["orange", "apple", "banana"])

結果は次のようになります。

['apple', 'banana', 'orange']

英語の小文字だけなら、基本的にアルファベット順になります。

ただし、Pythonの通常の文字列比較では、文字のコード順が使われます。

大文字や日本語が混ざる場合は、辞書で調べるような自然な順番になるとは限りません。

ミニ課題

問題1：数値を並べ替える

次のリストがあります。

prices = [300, 120, 500, 200]

sorted() を使って、小さい順と大きい順の両方を表示してください。

元のリストは変更しないでください。

ヒント：大きい順には reverse=True を使います。

問題2：sort() で並べ替える

次のリストがあります。

numbers = [9, 3, 7, 1]

sort() を使って、小さい順に並べ替えて表示してください。

ヒント：numbers.sort() のあとに print(numbers) を使います。

問題3：商品の価格順に並べる

次の辞書のリストがあります。

items = [
    {"商品": "りんご", "価格": 120},
    {"商品": "みかん", "価格": 80},
    {"商品": "バナナ", "価格": 150}
]

価格を取り出す関数 get_price() を作り、価格の高い順に並べて表示してください。

ヒント：key=get_price と reverse=True を組み合わせます。

答え例

# 問題1
print("問題1")

prices = [300, 120, 500, 200]

print("小さい順:", sorted(prices))
print("大きい順:", sorted(prices, reverse=True))
print("元のリスト:", prices)

# 問題2
print("\n問題2")

numbers = [9, 3, 7, 1]

numbers.sort()
print(numbers)

# 問題3
print("\n問題3")

items = [
    {"商品": "りんご", "価格": 120},
    {"商品": "みかん", "価格": 80},
    {"商品": "バナナ", "価格": 150}
]

def get_price(item):
    return item["価格"]

sorted_items = sorted(items, key=get_price, reverse=True)

for item in sorted_items:
    print(item["商品"], item["価格"], "円")

まとめ

今回は、sorted() と sort() を使って、データを並べ替える方法を学びました。

sorted() は元のリストを残し、sort() は元のリストを直接変更します。

さらに、key= を使えば、第19回で学んだ辞書のリストも、点数や価格などを基準に並べ替えられます。
