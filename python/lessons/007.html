目標

  • while を使って、条件が成り立つあいだ処理をくり返せるようになる。
  • for と while の使い分けを理解する。
  • 無限ループを防ぐために、変数を変化させる大切さを知る。

BASICとの比較
第6回では、for を使って決まった回数だけくり返す方法を学びました。

今回は、条件が成り立っているあいだ、何度も処理をくり返す while 文です。

BASICの WHILE〜WEND とよく似ています。

BASICPython
WHILE A < 5while a < 5:
PRINT Aprint(a)
A = A + 1a = a + 1
WENDインデントを戻して終了

BASICでは WEND でくり返しの終わりを示します。

Pythonでは WEND は使いません。インデント（字下げ）によって、くり返す範囲を決めます。

また、for は回数が決まっている処理に向き、while は条件によって終了を決めたい処理に向いています。

コード

# 第7回 while文の基本
# BASICのWHILE〜WENDと比べよう
print("while文の練習")

# 1から5まで数える
count = 1
while count <= 5:
    print("カウント:", count)
    count = count + 1
print("カウント終了！")

# 10から2ずつ減らす
number = 10
while number > 0:
    print("残り:", number)
    number = number - 2
print("すべて終了しました")

ポイント

  • ① while は「〜のあいだ」

while count <= 5: は、「count が5以下のあいだ、くり返す」という意味です。条件が True（真）のあいだ実行され、False（偽）になると終了します。

  • ② 最後にコロン : を付ける

if や for と同じように、while の行末には : が必要です。くり返す処理は、半角スペース4つで字下げします。

  • ③ 変数を変化させる

count = count + 1 は、count を1増やす命令です。BASICと同じ考え方です。Pythonでは count += 1 と短く書くこともできます。

  • ④ 無限ループに注意！

count を増やし忘れると、count <= 5 がずっと成り立ち、処理が終わらなくなります。while を書いたら、条件がいつか False になるか確認しましょう。

  • ⑤ for と while の違い

1から10まで数えるなど、回数が決まっているなら for が便利です。一方、条件が変わるまで続けたいときは while が便利です。なお、条件が最初から False なら、くり返しは一度も実行されません。

ミニ課題
while を使って、3から1までカウントダウンしてみましょう。

最初に count = 3 として、1ずつ減らします。

画面に次のように表示できれば成功です。

3
2
1
スタート！

ヒント：条件には count >= 1 を使います。

答え例

# 答え
count = 3
while count >= 1:
    print(count)
    count = count - 1
print("スタート！")
