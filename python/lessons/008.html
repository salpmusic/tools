第8回：リストの基本 ～BASICの配列 DIM と比べてみよう～

※TIOBE Index 2026年10月

目標

  • リストを使って、複数の値をひとまとめにする。
  • リストから番号（インデックス）を使って値を取り出す。
  • len() で個数を調べ、for 文で順番に取り出す。

BASICとの比較

BASICでは、複数のデータをまとめるときに「配列」を使いました。

例えば、3つの点数を保存するときは、次のように書けます。

10 DIM A(3)
20 A(1)=80
30 A(2)=90
40 A(3)=70
50 PRINT A(1)

Pythonでは「リスト」を使います。

scores = [80, 90, 70]
print(scores[0])

どちらも最初の点数「80」を表示します。

大きな違いは、Pythonのリストは0番から始まることです。

内容BASICの配列Pythonのリスト
準備DIM A(3)a = [80, 90, 70]
最初の値A(1)a[0]
2番目の値A(2)a[1]
3番目の値A(3)a[2]
値の取り出し丸カッコ ( )角カッコ [ ]
個数を調べる処理系によるlen(a)

※ BASICは種類や OPTION BASE の設定によって0始まりの場合もあります。また、DIM A(3) が確保する要素数も処理系によって異なります。

Pythonでは、3個のデータなら番号は 0、1、2 です。3 番を取り出そうとするとエラーになります。

コード

# 第8回：リストの基本
# 3つの点数をリストにまとめる
scores = [80, 90, 70]

# リスト全体を表示
print("点数一覧:", scores)

# 番号を指定して取り出す
print("1番目:", scores[0])
print("2番目:", scores[1])
print("3番目:", scores[2])

# len() で個数を調べる
print("点数の個数:", len(scores))

# for文で順番に取り出す
print("点数を順番に表示")
for score in scores:
    print(score)

# 合計と平均を計算する
total = 0
for score in scores:
    total = total + score
print("合計:", total)
print("平均:", total / len(scores))

ポイント

  • **リストは [ ] で作る。** scores = [80, 90, 70] のように、値をカンマで区切って並べます。数値だけでなく文字列も入れられます。
  • 番号は0から始まる。 scores[0] が最初、scores[1] が2番目です。3個のリストなら最後は scores[2] です。
  • **len() は個数を返す。** len(scores) の結果は 3 です。リストが長くなっても個数を自動で調べられます。
  • **for 文で値を順番に取り出せる。** for score in scores: と書けば、80、90、70が順番に score に入ります。第6回の for 文の応用です。
  • リストは後から変更できる。 値を書き換えたり、append() で追加したりできます。追加や削除の詳しい方法は次回学びます。

ミニ課題

好きな果物を3つ、リスト fruits に入れてみましょう。

次の3つを表示してください。

  • リスト全体
  • 2番目の果物
  • for 文を使って、果物を1つずつ表示

※ input() は使いません。果物の名前は自由に変えて構いません。

答え例

# 答え
fruits = ["りんご", "みかん", "バナナ"]

# リスト全体
print("果物一覧:", fruits)

# 2番目の果物
print("2番目:", fruits[1])

# 順番に表示
print("果物を順番に表示")
for fruit in fruits:
    print(fruit)
