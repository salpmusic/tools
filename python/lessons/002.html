第2回：変数と計算 ～BASICのLET A=1と比べてみよう～

※TIOBE Index 2026年10月

目標

  • 変数は「値を入れる箱」のようなもの。名前を付けて数字や文字を入れておき、あとで取り出して計算したり表示したりできる
  • BASICの LET A = 10 と Python の a = 10 の違いを知る
  • 足し算・掛け算・割り算などの計算をする

BASICとの比較

BASICでは次のように書いていましたね。

10 LET A = 10
20 LET B = 20
30 PRINT A + B

Pythonでは LET は不要で、もっとシンプルに書けます（a = 10 / b = 20 / print(a + b) で 30 と表示されます）。

BASICPython違い
LET A = 10a = 10**LET がいらない**：Pythonは 変数名 = 値 で代入します。
A と a は同じことが多いa と A は別の変数大文字と小文字を区別する：BASICでは区別しないことが多いので注意してください。
10 LET ...行番号なし行番号がいらない：Pythonは上から順に実行されます。

よく使う演算子はBASICとほぼ同じです。

演算記号例（結果）
足し算+5 + 3 → 8
引き算-5 - 3 → 2
掛け算*5 * 3 → 15
割り算/5 / 2 → 2.5
割り算（整数）//5 // 2 → 2
余り%5 % 2 → 1
べき乗**2 ** 3 → 8

コード（そのまま実行できる）

# 第2回：変数と計算 の例
# Python 3.7 対応

print("=== 変数の基本 ===")
a = 10
b = 20
print(a + b)

print("\n=== 計算の例 ===")
x = 7
y = 3
print(x + y)
print(x * y)
print(x ** 2)

print("\n=== 結果を変数に入れる ===")
total = a + b
print(total)

print("\n=== 練習問題1 ===")
price = 1200
tax = 1.1
print(price * tax)

print("\n=== 練習問題2 ===")
num = 17
print(num // 2)
print(num % 2)

print("\n=== 大文字小文字の違い（参考） ===")
score = 80
Score = 90
print(score) # 80
print(Score) # 90

ポイント

  • = は「等しい」ではなく「右の値を左の変数に入れる」という意味です。
  • 変数名は英字で始め、数字や _ を使えます（例：score、total_1）。
  • 計算した結果を別の変数に入れることもできます（例：total = a + b → print(total) で 30）。

ミニ課題

問題1：変数 price に 1200、変数 tax に 1.1 を代入し、税込み価格を計算して表示してください。

問題2：変数 num に 17 を入れ、2で割った商（整数）と余りをそれぞれ表示してください。

答え例

# 問題1（出力例：1320.0）
price = 1200
tax = 1.1
print(price * tax)

# 問題2（出力例：8 と 1）
num = 17
print(num // 2) # 商
print(num % 2) # 余り
