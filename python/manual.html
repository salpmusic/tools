PythonはBASICより「読みやすく」「構造をはっきり書ける」言語です。

第2章 変数とデータ型

変数は「名前をつけた箱」です。BASICと違い、LET は不要です。

BASICPython
LET a = 5a = 5
LET name$ = "Taro"name = "Taro"
型を宣言する必要は少ない型を宣言しない（動的型付け）

コード例

age = 20          # 整数
price = 1.5       # 小数
name = "塩田"     # 文字列
is_ok = True      # 真偽値（True/False）

print(age)
print(name)

第5章 リスト

リストは「複数の値を順番に入れる箱」です。BASICの配列に近いですが、より柔軟です。

コード例

fruits = ["りんご", "みかん", "バナナ"]
print(fruits[0])          # 最初の要素（0番目）
fruits.append("ぶどう")   # 追加
print(fruits)
▶ このコードを実行（軽量版） 🐧 PC向け Linux Lite
操作Python
作成a = [1, 2, 3]
長さlen(a)
追加a.append(4)
削除a.remove(2) または del a[0]

第6章 関数

BASICの GOSUB に近いですが、Pythonの関数は「引数と戻り値」を持てます。

BASICPython
GOSUB 1000def greet():
...

戻り値なしが多いreturn で値を返せる

コード例

    return a + b

result = add(3, 5)
print(result)  # 8
