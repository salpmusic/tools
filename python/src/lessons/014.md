# 第14回：関数の引数と戻り値 ～値を渡して結果をもらう～

**目標**
- 引数を2つ以上渡す関数を書けるようになる。
- `return` で返ってきた値を、変数に入れて計算や表示に使えるようになる。
- `return` は「関数をそこで終えて、値を呼び出し元へ返す」ことを理解する。

**BASICとの比較**

BASICでは、サブルーチンに値を渡すとき、先に変数へ入れてから `GOSUB` することが多いです。結果も、決まった変数に入れて戻ってきます。

BASICの例：

```
10 A = 70 : B = 90
20 GOSUB 100
30 PRINT "平均 ="; M
40 END
100 M = (A + B) / 2
110 RETURN
```

この書き方だと、「`A` と `B` に入れておく」「結果は `M` に入る」という約束を覚えておく必要があります。

Pythonでは、値を**引数**としてかっこの中で渡し、結果は **`return`** で受け取ります。共有の変数名に頼らなくてよいのが大きな違いです。

| やりたいこと | BASIC | Python |
|---|---|---|
| 値を渡す | 変数に入れてから `GOSUB` | `average(70, 90)` |
| 結果をもらう | 決まった変数（`M` など） | `avg = average(70, 90)` |
| 結果をさらに使う | 変数を読み直す | `price_with_tax(500) * 2` のようにそのまま使える |

**コード**
```python
# 第14回：関数の引数と戻り値

# 1. 引数を2つ渡す
def introduce(name, age):
    print(name + "さんは " + str(age) + " 歳です")


print("1. 引数を2つ")
introduce("太郎", 12)
introduce("花子", 15)


# 2. return で計算結果をもらう
def average(a, b):
    return (a + b) / 2


print("2. 戻り値で計算")
avg = average(70, 90)
print("70 と 90 の平均 =", avg)


# 3. 戻り値をさらに使う
def price_with_tax(price):
    return int(price * 1.1)


def make_label(item, price):
    return item + "：" + str(price) + "円"


print("3. 戻り値をつなげる")
pay = price_with_tax(500)
print(make_label("ノート", pay))
print("2冊なら", pay * 2, "円")
```

**実行結果の例**
```
1. 引数を2つ
太郎さんは 12 歳です
花子さんは 15 歳です
2. 戻り値で計算
70 と 90 の平均 = 80.0
3. 戻り値をつなげる
ノート：550円
2冊なら 1100 円
```

**ポイント**
- **引数はカンマで区切って**複数渡せます。`introduce("太郎", 12)` なら、`name` に `"太郎"`、`age` に `12` が順番に入ります。
- 数値を文字列と `+` でつなぐときは、**`str()`** で文字列に変えます。`str(age)` がその例です。
- **`return`** を通ると、関数はそこで終わり、値が呼び出した場所へ返ります。BASICの `RETURN` と違い、「値を持って帰る」のがポイントです。
- 返ってきた値は、**変数に入れても、そのまま別の関数や計算に使っても**大丈夫です。`make_label("ノート", pay)` や `pay * 2` のように組み合わせられます。
- `/` で割ると、結果は `80.0` のように小数になります。整数にしたいときは `int()` を使います。

**ミニ課題**

数を受け取って、その2乗（同じ数をかけたもの）を返す関数 `square` を作り、`square(4)` と `square(7)` の結果を表示してください。

ヒント：`return n * n` と書けば、かけ算の結果が返ります。

**答え例**
```python
# 答え
def square(n):
    return n * n

print(square(4))
print(square(7))
```

実行結果：

```
16
49
```

`square(4)` を呼ぶと `n` に `4` が入り、`4 * 4` の `16` が返ってきます。返ってきた値をそのまま `print` に渡しています。
