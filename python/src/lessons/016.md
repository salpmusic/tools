# 第16回：可変長引数 *args ～いくつでも受け取れる引数～

**目標**

- `*args` を使って、個数が決まっていない引数を受け取れるようになる。
- `*args` がタプルとして扱われることを知り、`sum()` や `len()` で合計・平均を計算する。
- 普通の引数と `*args` を組み合わせて、便利な関数を作る。

**BASICとの比較**

前回は、関数の引数に初期値を設定する「デフォルト引数」と、名前を指定して値を渡す「キーワード引数」を学びました。

今回は、引数の個数が決まっていない場合を考えてみましょう。

例えば、3人の点数を合計する関数を作ったあと、5人や10人の点数も合計したくなったらどうでしょう？

BASICでは、配列に値を入れてから、FOR文などで順番に計算する方法が考えられます。

BASIC風の疑似コード：

```
10 DIM A(3)
20 A(1)=80
30 A(2)=90
40 A(3)=70
50 S=0
60 FOR I=1 TO 3
70 S=S+A(I)
80 NEXT I
90 PRINT S
```

Pythonでは、`*args` を使うと、関数に渡す値の個数を自由に変えられます。

| 比較      | BASIC        | Python              |
| ------- | ------------ | ------------------- |
| 複数の値を扱う | 配列などを使う      | `*args` でまとめて受け取れる  |
| 個数の管理   | 配列のサイズや個数を管理 | 渡された個数に応じて受け取る      |
| 合計      | FOR文で加算      | `sum(args)`         |
| 個数      | 自分で管理することが多い | `len(args)`         |
| 呼び出し    | 配列を用意して渡すなど  | `total(10, 20, 30)` |

`*args` の `*` は、複数の位置引数をまとめて受け取るための記号です。

`args` は慣習的な名前で、別の名前でも動きます。

例えば `*numbers` や `*scores` と書くこともできます。

**コード**

```python
# 第16回：可変長引数 *args
# Python 3.7.3 対応

# 1. いくつでも数を受け取る
def total(*args):
    return sum(args)

print("1. 合計")
print(total(10, 20))
print(total(10, 20, 30))
print(total(5, 10, 15, 20))


# 2. args の中身を確認する
def show_numbers(*args):
    print("受け取った値:", args)
    print("個数:", len(args))

print("\n2. args の中身")
show_numbers(10, 20, 30)


# 3. 平均を計算する
def average(*args):
    if len(args) == 0:
        return 0
    return sum(args) / len(args)

print("\n3. 平均")
print(average(80, 90, 70))
print(average(60, 80))
print(average())


# 4. 普通の引数と *args を組み合わせる
def show_scores(label, *scores):
    print(label)
    print("点数:", scores)

    if len(scores) == 0:
        print("平均: データなし")
    else:
        avg = sum(scores) / len(scores)
        print(f"平均: {avg:.1f}点")

print("\n4. 点数の表示")
show_scores("国語", 80, 90, 70)
show_scores("数学", 95, 85)
show_scores("英語")


# 5. print も複数の値を受け取れる
print("\n5. print の例")
print("りんご", "みかん")
print("赤", "青", "緑", "黄色")


# 6. *args を for 文で取り出す
def show_items(*args):
    for item in args:
        print("商品:", item)

print("\n6. 商品一覧")
show_items("パン", "牛乳", "卵")
```

**ポイント**

- `*args` は、0個以上の位置引数をまとめて受け取る書き方です。
- 受け取った値は、`(10, 20, 30)` のような「タプル」になります。タプルはリストに似ていますが、作成後に中身を変更できないデータのまとまりです。
- `sum(args)` で数値の合計、`len(args)` で個数を求められます。
- `*args` に値が1つも渡されなかった場合は、空のタプル `()` になります。
- 平均を計算するときは、個数が0の場合に注意しましょう。0で割るとエラーになるため、先に `len(args) == 0` を確認します。
- `def show_scores(label, *scores):` のように、普通の引数と組み合わせることもできます。
- `*args` の名前は自由です。`*scores` や `*items` など、意味の分かりやすい名前でも構いません。
- `print()` も複数の値を渡せる関数です。`*args` を理解するための身近な例になります。ただし、`print()` 自体は表示のための追加機能も持っています。
- `*args` は位置引数をまとめて受け取ります。名前付きの引数をまとめて受け取る `**kwargs` という書き方もありますが、こちらは次回学びます。

**ミニ課題**

課題1：最大値を求めよう

`*args` を使って、渡された数の中から一番大きな値を返す `maximum()` 関数を作ってみましょう。

例えば、`maximum(10, 50, 30)` の結果は `50` です。

ヒント：Pythonには、最大値を求める `max()` 関数があります。引数が0個の場合は、先に確認しましょう。

課題2：好きな食べ物を表示しよう

`*foods` を使って、渡された食べ物を1つずつ表示する `show_foods()` 関数を作ってみましょう。

例えば、`show_foods("カレー", "ラーメン", "寿司")` と呼び出します。

ヒント：`for food in foods:` を使います。

課題3：教科ごとの合計点を表示しよう

普通の引数 `subject` と可変長引数 `*scores` を使って、教科名と合計点を表示する `subject_total()` 関数を作ってみましょう。

例えば、`subject_total("算数", 80, 90, 100)` と呼び出します。

ヒント：`sum(scores)` を使えば、点数をまとめて合計できます。

**答え例**

```python
# 課題1：最大値
def maximum(*args):
    if len(args) == 0:
        return None
    return max(args)

print("課題1")
print(maximum(10, 50, 30))
print(maximum(8, 3))
print(maximum())


# 課題2：食べ物の一覧
def show_foods(*foods):
    for food in foods:
        print("好きな食べ物:", food)

print("\n課題2")
show_foods("カレー", "ラーメン", "寿司")


# 課題3：教科ごとの合計点
def subject_total(subject, *scores):
    total = sum(scores)
    print(f"{subject}の合計: {total}点")

print("\n課題3")
subject_total("算数", 80, 90, 100)
subject_total("国語", 70, 85)
```

```

```

`None` は「値がない」ことを表すPythonの特別な値です。課題1では、数が1つも渡されなかったときに返しています。

今回は、`*args` を使って、引数をいくつでも受け取れる関数を作りました。

これで、人数やデータの個数が変わっても、同じ関数を使えるようになりました。
