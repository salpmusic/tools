# 第19回：リストと辞書の入れ子 ～複数のデータをひとまとめにする～

**目標**

- リストの中に辞書を入れて、複数の情報をまとめて管理できる。
- 入れ子になったデータから、必要な情報を取り出せる。
- ループや関数を使って、複数のデータをまとめて処理できる。

**BASICとの比較**

第18回では、辞書の `items()` や `get()`、更新や削除の方法を学びました。

今回は、これまで学んだリストと辞書を組み合わせて、もう少し複雑なデータを扱ってみましょう。

例えば、3人の生徒について「名前」「年齢」「点数」を管理したいとします。

BASICでは、次のように複数の配列を使う方法があります。

```
10 DIM N$(3), A(3), S(3)
20 N$(1)="太郎": A(1)=20: S(1)=80
30 N$(2)="花子": A(2)=19: S(2)=90
40 N$(3)="三郎": A(3)=21: S(3)=75
50 FOR I=1 TO 3
60 PRINT N$(I), A(I), S(I)
70 NEXT I
```

Pythonでは、1人分の情報を辞書にまとめ、その辞書をリストに入れることができます。

| やりたいこと | BASICの考え方 | Python |
|---|---|---|
| 1人分の情報を管理 | 複数の配列の同じ番号 | 1つの辞書 |
| 複数人を管理 | 配列を人数分用意 | 辞書をリストに入れる |
| 1人を取り出す | 配列の番号を指定 | リストの番号を指定 |
| 名前や点数を取り出す | 対応する配列を選ぶ | 辞書のキーを指定 |
| 全員を処理する | FOR文 | for文 |

このように、データの中に別のデータを入れることを「入れ子（ネスト）」と呼びます。

**コード**

```python
# 第19回：リストと辞書の入れ子
# 複数のデータをひとまとめにする

# 1. リストの中に辞書を入れる
print("1. リストの中に辞書")

students = [
    {"名前": "太郎", "年齢": 20, "点数": 80},
    {"名前": "花子", "年齢": 19, "点数": 90},
    {"名前": "三郎", "年齢": 21, "点数": 75}
]

print("人数:", len(students))
print("最初の生徒:", students[0])

# 2. 入れ子のデータを取り出す
print("\n2. データを取り出す")

print("最初の名前:", students[0]["名前"])
print("2番目の点数:", students[1]["点数"])

# 3. ループで全員を表示する
print("\n3. 全員の情報")

for student in students:
    print(f"{student['名前']}さん "
          f"{student['年齢']}歳 "
          f"{student['点数']}点")

# 4. 入れ子のデータを変更する
print("\n4. 点数を変更する")

students[0]["点数"] = 85

print("太郎の新しい点数:", students[0]["点数"])

# 5. 条件に合うデータを取り出す
print("\n5. 80点以上の生徒")

for student in students:
    if student["点数"] >= 80:
        print(student["名前"], student["点数"], "点")

# 6. 関数で合計と平均を計算する
print("\n6. 合計と平均")

def average_score(data):
    total = 0
    for student in data:
        total += student["点数"]
    if len(data) == 0:
        return 0
    return total / len(data)

total = sum(student["点数"] for student in students)

print("合計:", total)
print("平均:", average_score(students))

# 7. 辞書の中にリストを入れる
print("\n7. 辞書の中にリスト")

school = {
    "学校名": "さくら学校",
    "教科": ["国語", "数学", "英語"]
}

print("学校名:", school["学校名"])
print("教科:", school["教科"])
print("最初の教科:", school["教科"][0])
```

**実行結果の例**


**ポイント**

### 1. リストの中に辞書を入れられる

例えば、次のように書けます。

```
students = [
    {"名前": "太郎", "点数": 80},
    {"名前": "花子", "点数": 90}
]
```

リストの1つの要素が、1人分の辞書になっています。

これなら、人数が増えても同じ形で情報を管理できます。

### 2. 番号とキーを組み合わせて取り出す

```
students[0]["名前"]
```

この書き方は、左から順番に考えるとわかりやすいです。

- `students[0]` で最初の生徒の辞書を取り出す。
- `["名前"]` で、その辞書の名前を取り出す。

リストの番号は、第8回で学んだように0から始まります。

### 3. for文で1人ずつ処理できる

```
for student in students:
    print(student["名前"])
```

`student` には、リストの中の辞書が1つずつ入ります。

そのため、名前や年齢、点数をキーで取り出せます。

### 4. 入れ子の中身も変更できる

```
students[0]["点数"] = 85
```

この書き方で、最初の生徒の点数を変更できます。

第12回で学んだ辞書の更新と、考え方は同じです。

### 5. 関数にまとめて渡せる

```
def average_score(data):
    total = 0
    for student in data:
        total += student["点数"]
    if len(data) == 0:
        return 0
    return total / len(data)
```

辞書が入ったリストも、普通のリストと同じように関数へ渡せます。

関数の中で1人ずつ点数を取り出せば、平均点などを計算できます。

なお、本編の `sum()` は、数値を合計するための組み込み関数です。

```
sum(student["点数"] for student in students)
```

これは、各生徒の点数を順番に取り出して合計しています。

少し短い書き方ですが、最初は `for` を使って合計しても大丈夫です。

また、平均を求める前に `len(data) == 0` を確認しているのは、データが空のときに0で割るエラーを防ぐためです。

### 6. 辞書の中にリストを入れることもできる

```
school = {
    "学校名": "さくら学校",
    "教科": ["国語", "数学", "英語"]
}
```

この場合、「教科」というキーの値がリストになっています。

```
school["教科"][0]
```

と書けば、最初の教科である「国語」を取り出せます。

リストの中に辞書、辞書の中にリスト。

どちらも、これまで学んだ基本操作を組み合わせているだけです。

**ミニ課題**

### 問題1：商品の一覧を表示する

次のデータがあります。

```
items = [
    {"商品": "りんご", "価格": 120},
    {"商品": "みかん", "価格": 80},
    {"商品": "バナナ", "価格": 150}
]
```

`for` 文を使って、商品名と価格をすべて表示してください。

ヒント：リストから辞書を1つずつ取り出し、`["商品"]` と `["価格"]` を使います。

### 問題2：条件に合う商品を表示する

問題1のデータから、100円以上の商品だけを表示してください。

ヒント：`if item["価格"] >= 100:` を使います。

### 問題3：商品の合計金額を求める

問題1のデータを関数に渡して、すべての商品の価格を合計する `total_price()` 関数を作ってください。

ヒント：`total = 0` から始めて、`for` 文で価格を足し、最後に `return total` を使います。

**答え例**

```python
items = [
    {"商品": "りんご", "価格": 120},
    {"商品": "みかん", "価格": 80},
    {"商品": "バナナ", "価格": 150}
]

# 問題1
print("問題1")

for item in items:
    print(item["商品"], item["価格"], "円")

# 問題2
print("\n問題2")

for item in items:
    if item["価格"] >= 100:
        print(item["商品"], item["価格"], "円")

# 問題3
print("\n問題3")

def total_price(data):
    total = 0
    for item in data:
        total += item["価格"]
    return total

print("合計:", total_price(items), "円")
```

```

みかん 80 円
バナナ 150 円

問題2
りんご 120 円
バナナ 150 円

問題3
合計: 350 円
```
