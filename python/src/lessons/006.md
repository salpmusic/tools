# 第6回：for文とrange ～BASICのFOR...NEXTと比べてみよう～

**目標**
- `for`文を使って、決まった回数だけ処理をくり返せるようになる。
- `range()`で、くり返す回数や数字の範囲を指定できるようになる。
- BASICの`FOR...NEXT`とPythonの違いを理解する。

**BASICとの比較**

BASICでは、同じ処理をくり返すときに`FOR...NEXT`を使いました。

BASICの例：

```
FOR I = 1 TO 10
  PRINT I
NEXT I
```

Pythonでは、次のように書きます。

```
for i in range(1, 11):
    print(i)
```

どちらも1から10までの数字を表示します。

大きな違いは、Pythonの`range()`では**最後の数字を含まない**ことです。

| BASIC | Python |
|---|---|
| FOR I=1 TO 10 | for i in range(1, 11): |
| FOR I=1 TO 10 STEP 2 | for i in range(1, 11, 2): |
| NEXT I | 不要（インデントで区切る） |
| PRINT I | print(i) |

**コード**
```python
# 第6回：for文とrange

# 1. 5回くり返す
print("1. 5回くり返す")
for i in range(5):
    print("こんにちは", i)

# 2. 1から5まで表示
print("2. 1から5まで")
for i in range(1, 6):
    print(i)

# 3. 2ずつ増やす
print("3. 奇数を表示")
for i in range(1, 10, 2):
    print(i)

# 4. くり返しで合計を計算
print("4. 1から5の合計")
total = 0
for i in range(1, 6):
    total = total + i
print("合計 =", total)
```

**ポイント**
- `for`はくり返しの命令。`for i in range(5):`と書くと、`i`が0から4まで変わり、5回くり返します。
- `range(n)`は0から始まる。`range(5)`なら0、1、2、3、4です。5は含まれません。
- `range(start, stop)`は開始と終了を指定。`range(1, 6)`なら1から5までです。終了の6は含まれません。
- `range(start, stop, step)`は増え方も指定。`range(1, 10, 2)`なら1、3、5、7、9です。`step`に負の数を指定すれば逆向きにも数えられます。
- インデントが大切。第5回の`if`文と同じです。`for`の行末には`:`を付け、くり返す処理は半角スペース4つ下げます。BASICの`NEXT`は必要ありません。

**ミニ課題**

BASICの次のプログラムをPythonに書き換えてみましょう。

```
FOR I=2 TO 10 STEP 2
  PRINT I
NEXT I
```

2、4、6、8、10の5つの数字を、`for`と`range()`を使って表示してください。

ヒント：Pythonでは最後の数字を含まないので、`stop`を11にします。

**答え例**
```python
# 答え
for i in range(2, 11, 2):
    print(i)
```

実行結果：

```
2
4
6
8
10
```

BASICの`FOR I=2 TO 10 STEP 2`は、Pythonでは`for i in range(2, 11, 2):`になります。
