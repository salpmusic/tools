**BASICとの比較**

### 2. PythonとBASICの計算記号

| 計算 | BASIC | Python |
|---|---|---|
| 足し算 | `A + B` | `a + b` |
| 引き算 | `A - B` | `a - b` |
| 掛け算 | `A * B` | `a * b` |
| 普通の割り算 | `A / B` | `a / b` |
| 整数の商 | `A \ B` | `a // b` |
| 余り | `A MOD B` | `a % b` |
| べき乗 | `A ^ B` | `a ** b` |

※ BASICの記号は、Microsoft系BASICなどを想定しています。方言によって違いがあります。

#### 普通の割り算 `/` と整数の商 `//`

Pythonで `7 / 2` を計算すると、答えは `3.5` になります。

一方、`7 // 2` は小数部分を切り下げて `3` になります。

```
print(7 / 2)    # 3.5
print(7 // 2)   # 3
```

BASICの `\` に近いのが、Pythonの `//` です。

**ポイント：** `//` は単純に小数部分を取り除くのではなく、マイナス方向へ切り下げます。

```
print(-7 // 2)  # -4
```

マイナスの計算では特に注意しましょう。

#### 余り `%` とべき乗 `**`

BASICの `MOD` は、Pythonでは `%` です。

```
print(10 % 3)   # 1
```

10を3で割ると、3が3回入り、1が余ります。

べき乗は、同じ数を何回も掛ける計算です。

BASICでは `2 ^ 3` と書きますが、Pythonでは `2 ** 3` です。

```
print(2 ** 3)   # 8
```

2 × 2 × 2 = 8 になります。

Pythonの `^` はべき乗ではなく、別の用途の記号なので間違えないようにしましょう。

### 3. 計算の順番とカッコ

Pythonも算数と同じように、掛け算や割り算を足し算より先に計算します。

```
print(2 + 3 * 4)    # 14
print((2 + 3) * 4)  # 20
```

最初の計算は、3 × 4 を先に計算するので14です。

2つ目は、カッコの中を先に計算するので20になります。

**基本の順番**

- カッコ `()`
- べき乗 `**`
- 掛け算・割り算・整数の商・余り `* / // %`
- 足し算・引き算 `+ -`

同じ優先順位の演算は基本的に左から計算しますが、`**` は右から結びつきます。

迷ったらカッコを使うと、計算の意味がはっきりします。

### 4. 小数の誤差と `round()`

コンピューターでは、小数を正確に表せないことがあります。

```
print(0.1 + 0.2)
```

実行結果：

```
0.30000000000000004
```

これはPythonの故障ではありません。

小数をコンピューター内部の2進数で扱うときに起こる、わずかな誤差です。

表示する桁数を整えたい場合は、`round()` が使えます。

```
print(round(0.1 + 0.2, 2))
```

結果：

```
0.3
```

`round(数値, 桁数)` と書きます。

ただし、`round()` はすべての小数誤差を解消するものではありません。また、ちょうど中間の値では偶数側へ丸める規則を使います。金額などの厳密な計算では、別の方法が必要になることもあります。

### 5. `print()` で結果を見やすく表示

数字だけ表示するよりも、何の計算結果なのか分かるようにすると便利です。

```
print("割り算の結果:", 7 / 2)
```

実行結果：

```
割り算の結果: 3.5
```

第3回で学んだ f-string も使えます。

```
a = 10
b = 3

print(f"{a} ÷ {b} = {a / b:.2f}")
```

実行結果：

```
10 ÷ 3 = 3.33
```

`:.2f` は、小数点以下を2桁で表示する指定です。

`round()` は丸めた数値を返しますが、`:.2f` は表示する形を整えます。

例えば `3.5` を `:.2f` で表示すると `3.50` になります。

**コード（そのまま実行できる）**

以下をそのままコピーしてPython 3.7で実行できます。`input()` は使わず、各計算結果を順番に確認できます。

```python
# Python入門 第4回
# 四則演算と計算結果の表示
# Python 3.7対応

print("=== 第4回：四則演算 ===")

# 1. 基本の四則演算
print("\n【1】基本の計算")
print("7 + 2 =", 7 + 2)
print("7 - 2 =", 7 - 2)
print("7 * 2 =", 7 * 2)
print("7 / 2 =", 7 / 2)

# 2. 割り算の違い
# BASICの \ に近いのが //
print("\n【2】割り算の違い")
print("7 / 2 =", 7 / 2)
print("7 // 2 =", 7 // 2)
print("-7 // 2 =", -7 // 2)

# 3. 余りとべき乗
# BASIC: MOD -> Python: %
# BASIC: ^   -> Python: **
print("\n【3】余りとべき乗")
print("10 % 3 =", 10 % 3)
print("2 ** 3 =", 2 ** 3)

# 4. 計算の順番
print("\n【4】計算の順番")
print("2 + 3 * 4 =", 2 + 3 * 4)
print("(2 + 3) * 4 =", (2 + 3) * 4)
print("2 ** 3 ** 2 =", 2 ** 3 ** 2)

# 5. 小数の誤差
print("\n【5】小数の誤差")
print("0.1 + 0.2 =", 0.1 + 0.2)
print("roundの結果 =", round(0.1 + 0.2, 2))

# 6. 結果を見やすく表示
print("\n【6】printとf-string")
a = 10
b = 3

print("普通の割り算:", a / b)
print(f"{a} ÷ {b} = {a / b:.2f}")
print(f"整数の商 = {a // b}")
print(f"余り = {a % b}")

# 7. 練習問題の答え合わせ
print("\n【7】練習問題")

print("問題1")
print("17 // 5 =", 17 // 5)
print("17 % 5 =", 17 % 5)
print("3 ** 2 =", 3 ** 2)

print("問題2")
print("10 + 6 / 2 =", 10 + 6 / 2)
print("(10 + 6) / 2 =", (10 + 6) / 2)

print("\n第4回はここまで！")
```

**ポイント**

**ミニ課題**

**問題1：** 次の計算結果は、それぞれいくつでしょう？

```
print(17 // 5)
print(17 % 5)
print(3 ** 2)
```

**問題2：** 次の2つの計算結果は、どう違うでしょう？

```
print(10 + 6 / 2)
print((10 + 6) / 2)
```

**答え例**

**問題1の答え**

`3`、`2`、`9`

17 ÷ 5 の整数の商は3、余りは2。3の2乗は9です。

**問題2の答え**

最初は `13.0`、2つ目は `8.0`。

最初は6 ÷ 2を先に計算し、2つ目は10 + 6を先に計算します。
