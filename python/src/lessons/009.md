# 第9回：リストの追加と削除 ～BASICの配列との違い～

**目標**
- append() を使って、リストの末尾に新しい値を追加できる。
- remove() と pop() を使って、リストから値を削除できる。
- BASICの配列とPythonのリストの違いを理解する。

**BASICとの比較**

BASICでは、配列を使うときに `DIM A(10)` のように大きさを決めることが一般的でした。

Pythonのリストは、最初に大きさを決める必要がありません。あとから値を追加したり、不要な値を削除したりできます。

| 操作 | BASIC | Python |
|---|---|---|
| 配列を用意 | `DIM A(10)` | `a = [10, 20, 30]` |
| 値を書き換える | `A(1) = 100` | `a[0] = 100` |
| 末尾に追加 | 配列の範囲内で管理するなど | `a.append(40)` |
| 値を削除 | 要素をずらすなどの処理が必要 | `a.remove(20)` |
| 番号で取り出して削除 | 自分で処理を作る | `a.pop(0)` |

※BASICの配列は方言によって番号の始まり方やサイズ変更の方法が異なります。Pythonのリストは必ず0番から始まります。

**コード**
```python
# 第9回 リストの追加と削除
scores = [60, 70, 80]
print("最初:", scores)

# appendで末尾に追加
scores.append(90)
print("追加後:", scores)

# 値を書き換える
scores[0] = 100
print("書き換え後:", scores)

# removeで値を指定して削除
scores.remove(70)
print("70を削除:", scores)

# popで番号を指定して取り出す
taken = scores.pop(1)
print("取り出した値:", taken)
print("pop後:", scores)

# pop()は末尾を取り出す
last = scores.pop()
print("末尾の値:", last)
print("最後:", scores)
```

**実行結果の例**
```
最初: [60, 70, 80]
追加後: [60, 70, 80, 90]
書き換え後: [100, 70, 80, 90]
70を削除: [100, 80, 90]
取り出した値: 80
pop後: [100, 90]
末尾の値: 90
最後: [100]
```

**ポイント**
- `append(値)` は追加：リストのいちばん後ろに値を追加します。追加するとリストの長さも増えます。
- `remove(値)` は値で削除：指定した値を探して削除します。同じ値が複数ある場合は、最初に見つかった1つだけを削除します。値が見つからないとエラーになります。
- `pop(番号)` は取り出して削除：指定した番号の値を取り出し、同時にリストから削除します。番号を省略した `pop()` は末尾を取り出します。空のリストからは取り出せません。
- 値の書き換えは `リスト[番号] = 値`：例えば `scores[0] = 100` で最初の値を100に変更できます。番号は0から始まります。
- Pythonのリストは大きさを変えられる：BASICの固定長配列と違い、追加や削除で要素数が変わります。途中に追加する `insert()` もありますが、今回は覚えなくても大丈夫です。

**ミニ課題**

好きな果物を管理するリストを作ってみましょう。

最初のリストは `["apple", "banana", "orange"]` です。

1. `append()` で `"grape"` を追加する。
2. `remove()` で `"banana"` を削除する。
3. `pop()` で最後の果物を取り出し、変数 `fruit` に入れる。
4. 取り出した果物と、残ったリストを `print()` で表示する。

**答え例**
```python
# 答え
fruits = ["apple", "banana", "orange"]
fruits.append("grape")
fruits.remove("banana")
fruit = fruits.pop()
print("取り出した果物:", fruit)
print("残った果物:", fruits)
```

実行すると、次のように表示されます。

```
取り出した果物: grape
残った果物: ['apple', 'orange']
```
