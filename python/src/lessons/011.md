# 第11回：for文でリストを回す ～BASICの配列のFORループと比べてみよう～

**目標**
- `for` 文でリストの中身を、先頭から順に取り出して使えるようになる。
- 値だけ欲しいときと、番号も欲しいときの書き方を使い分けられるようになる。
- BASICの配列を `FOR` で回す書き方との違いを理解する。

**BASICとの比較**

BASICでは、配列の中身を順に見るとき、番号を増やしながら取り出します。

BASICの例：

```
DIM A(3)
A(1)=80
A(2)=90
A(3)=70
FOR I=1 TO 3
  PRINT A(I)
NEXT I
```

Pythonでも同じことができますが、**値だけ欲しいとき**は番号を書かなくても回せます。

```
scores = [80, 90, 70]
for score in scores:
    print(score)
```

番号も一緒に使いたいときは、第6回の `range()` と第10回のインデックスを組み合わせます。

| やりたいこと | BASIC | Python |
|---|---|---|
| 値を順に表示 | `FOR I=1 TO N: PRINT A(I)` | `for x in a:` |
| 番号付きで表示 | 上と同じ（`I` を使う） | `for i in range(len(a)):` |
| 個数 | 処理系による | `len(a)` |
| 値の取り出し | `A(I)` | `a[i]` |

第8回で見た `for score in scores:` を、今回はもう少し丁寧に使い分けます。

**コード**
```python
# 第11回：for文でリストを回す

# 1. 値だけ順に取り出す
fruits = ["りんご", "みかん", "バナナ"]
print("1. 果物を順番に")
for fruit in fruits:
    print(fruit)


# 2. 合計を求める（値だけあればよい例）
scores = [80, 90, 70]
print("2. 点数の合計")
total = 0
for score in scores:
    total = total + score
print("合計 =", total)


# 3. 番号も欲しいとき（BASICの添字ループに近い）
names = ["太郎", "花子", "次郎"]
print("3. 番号付きで表示")
for i in range(len(names)):
    print(i, "番目:", names[i])


# 4. 表示用に番号を1からにする
print("4. 1から数える表示")
for i in range(len(names)):
    print(i + 1, "人目:", names[i])
```

**実行結果の例**
```
1. 果物を順番に
りんご
みかん
バナナ
2. 点数の合計
合計 = 240
3. 番号付きで表示
0 番目: 太郎
1 番目: 花子
2 番目: 次郎
4. 1から数える表示
1 人目: 太郎
2 人目: 花子
3 人目: 次郎
```

**ポイント**
- **値だけ欲しいとき**は `for fruit in fruits:` が一番わかりやすいです。リストの中身が、順に `fruit` に入ります。
- **番号も欲しいとき**は `for i in range(len(names)):` を使い、`names[i]` で値を取り出します。BASICの `FOR I=1 TO N` に近い書き方です。
- **`len(names)`** は個数です。3個なら `range(3)` なので、`i` は 0、1、2 になります。
- **人が読む番号**を1からにしたいときは、表示のときだけ `i + 1` にします。リストのインデックス自体は、これまでどおり 0 からです。
- 第8回の復習です。リストの追加・削除（第9回）やスライス（第10回）で作ったリストも、同じように `for` で回せます。

**ミニ課題**

次のリストがあります。

```
colors = ["赤", "青", "緑"]
```

`for` と `range(len(...))` を使って、次のように表示してください。

```
1: 赤
2: 青
3: 緑
```

ヒント：インデックスは 0 から始まります。表示する番号だけ `i + 1` にしましょう。

**答え例**
```python
# 答え
colors = ["赤", "青", "緑"]

for i in range(len(colors)):
    print(f"{i + 1}: {colors[i]}")
```

実行結果：

```
1: 赤
2: 青
3: 緑
```

`range(len(colors))` で 0、1、2 を作り、`colors[i]` で色を取り出しています。表示の番号だけ `i + 1` にしているので、1から数えられます。
