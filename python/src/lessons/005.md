# 第5回：比較とif文（BASICのIF〜THEN〜ELSEとの比較、== と = の違い、インデント、elif）

**目標**

前回までで「計算」と「文字列」まで進みました。今回はプログラムの中で「条件によって処理を分ける」方法を学びます。

BASICを知っている人にとっては「IF〜THEN〜ELSE」と同じようなことを、Pythonでは少し違う書き方で実現します。

特に重要なのが「== と = の違い」と「インデント（字下げ）」です。ゆっくり見ていきましょう。

**BASICとの比較**

### BASICのIF〜THEN〜ELSEを思い出そう

BASICではだいたい次のような書き方でした。

```
IF age >= 18 THEN
  PRINT "成人です"
ELSE
  PRINT "未成年です"
END IF
```

- IF の後に条件を書き、THEN で処理を始めます。

- 複数行にわたる場合は END IF で閉じます。

- ELSE は「条件が偽のとき」の処理です。

Pythonでも同じことができるのですが、書き方が少し違います。

### Pythonの比較演算子

条件を書くときに使う記号です。BASICとほぼ同じ意味です。

| 記号 | 意味 | 例 |
|---|---|---|
| == | 等しい | a == 10 |
| != | 等しくない | a != 10 |
| < | より小さい | a < 10 |
| > | より大きい | a > 10 |
| <= | 以下 | a <= 10 |
| >= | 以上 | a >= 10 |

**注意：** 等しいかどうか調べるときは **必ず ==（イコール2つ）** を使います。

### == と = の大きな違い

ここが今回いちばん大事なポイントです。

- = …… **代入**（値を入れる）
例：age = 20　→　age に 20 を入れる

- == …… **比較**（等しいかどうかを調べる）
例：age == 20　→　age が 20 かどうかを調べる（結果は True か False）

BASICでも = は代入と条件の両方で使われることがありましたが、Pythonでははっきり分かれています。

条件の中で = を書いてしまうとエラーになります。

### if文の書き方とインデント

Pythonのif文は次のように書きます。

```
if age >= 18:
    print("成人です")
else:
    print("未成年です")
```

ポイントは3つあります。

1. 条件の最後に **コロン :** を付ける

2. 条件が真のときに実行する処理は、**必ず字下げ（インデント）** する（通常はスペース4つ）

3. else も同じようにコロンを付け、その下の処理を字下げする

BASICの THEN や END IF に相当するものが「コロン + インデント」です。

インデントがずれているとエラーになるので、気をつけましょう。

### elif と else

条件が複数ある場合は elif（else if の略）を使います。

```
if score >= 80:
    print("よくできました")
elif score >= 60:
    print("合格です")
else:
    print("もう少し頑張りましょう")
```

- if から始まって、上から順に条件を調べます。

- 最初に真になったところの処理だけが実行されます。

- どの条件にも当てはまらなければ else が実行されます。

- elif はいくつでも書けます。

BASICの ELSEIF や、複数の IF を並べるのと同じ役割です。

**コード**

```python
# 第5回：比較とif文の例

print("=== 比較演算子の例 ===")
a = 10
b = 20
print("a == 10 :", a == 10)
print("a != 10 :", a != 10)
print("a < b   :", a < b)
print("a > b   :", a > b)
print("a <= 10 :", a <= 10)
print("a >= 20 :", a >= 20)
print()

print("=== if文の基本 ===")
age = 18
if age >= 18:
    print("成人です")
else:
    print("未成年です")
print()

print("=== elif の例 ===")
score = 75
if score >= 80:
    print("よくできました")
elif score >= 60:
    print("合格です")
else:
    print("もう少し頑張りましょう")
print()

print("=== 練習問題1の実行結果 ===")
temp = 25
if temp >= 30:
    print("暑いです")
elif temp >= 20:
    print("ちょうどいいです")
else:
    print("寒いです")
print()

print("=== 練習問題2の実行結果 ===")
name = "太郎"
if name == "太郎":
    print("こんにちは、太郎さん")
else:
    print("はじめまして")
print()

print("=== == と = の違い（エラーにならない例） ===")
x = 5          # これは代入
print("x の値:", x)
if x == 5:     # これは比較
    print("x は 5 です")
```

**実行結果の例**

```
=== 比較演算子の例 ===
a == 10 : True
a != 10 : False
a < b   : True
a > b   : False
a <= 10 : True
a >= 20 : False

=== if文の基本 ===
成人です

=== elif の例 ===
合格です

=== 練習問題1の実行結果 ===
ちょうどいいです

=== 練習問題2の実行結果 ===
こんにちは、太郎さん

=== == と = の違い（エラーにならない例） ===
x の値: 5
x は 5 です
```

**ポイント**

- 等しいかどうかを調べるときは **==** を使う（= は代入専用）

- if文の条件の後には必ず **:** を付ける

- 実行する処理は **インデント（字下げ）** する

- 複数の条件は elif でつなぐ

- else は「どれにも当てはまらなかったとき」の処理

**ミニ課題**

**問題1**

**問題1**

変数 temp に 25 が入っています。次の条件でメッセージを表示するプログラムを書いてください。

- 30以上なら「暑いです」

- 20以上30未満なら「ちょうどいいです」

- それ以外なら「寒いです」

**問題2**

変数 name に "太郎" が入っています。

name が "太郎" と等しいかどうかを調べて、等しい場合は「こんにちは、太郎さん」、等しくない場合は「はじめまして」と表示してください。

（== と = の違いに注意）

**答え例**

**問題1の答え**

```
temp = 25
if temp >= 30:
    print("暑いです")
elif temp >= 20:
    print("ちょうどいいです")
else:
    print("寒いです")
```

**問題2の答え**

```
name = "太郎"
if name == "太郎":
    print("こんにちは、太郎さん")
else:
    print("はじめまして")
```
