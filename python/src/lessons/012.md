# 第12回：辞書の基本 ～BASICにない「キーと値」の考え方を知ろう～

**目標**
- 辞書（dict）が「キー」と「値」のセットだと分かる。
- キーを指定して値を取り出す・追加する・書き換えるができる。
- リスト（番号で取り出す）と辞書（名前で取り出す）の違いを理解する。

**BASICとの比較**

BASICの配列は、だいたい**番号**で中身を取り出します。名前で点数を知りたいときは、名前用の配列と点数用の配列を別々に用意して、同じ番号で対応させることがよくあります。

BASICに近いイメージ：

```
DIM N$(3), S(3)
N$(1)="太郎" : S(1)=80
N$(2)="花子" : S(2)=90
N$(3)="次郎" : S(3)=70
```

「太郎の点数は？」と聞くには、名前の配列を探して番号を見つけ、その番号で点数配列を見る必要があります。

Pythonの**辞書**は、最初から「名前 → 点数」のように、キーで直接取り出せます。

```
scores = {"太郎": 80, "花子": 90, "次郎": 70}
print(scores["太郎"])
```

| やりたいこと | BASIC（配列のイメージ） | Python |
|---|---|---|
| 番号で取り出す | `A(1)` | リスト `a[0]` |
| 名前で取り出す | 名前配列＋点数配列など | 辞書 `d["太郎"]` |
| 新しい組を足す | 配列を広げて代入 | `d["三郎"] = 85` |
| あるか調べる | ループで探すことが多い | `"花子" in d` |

BASICに「辞書」そのものはありません。番号ではなく**キー（名前など）**で値を探す、という考え方が新しいポイントです。

**コード**
```python
# 第12回：辞書の基本

# 1. 辞書を作る（キー: 値）
scores = {"太郎": 80, "花子": 90, "次郎": 70}
print("1. 辞書そのもの")
print(scores)


# 2. キーで値を取り出す
print("2. キーで取り出す")
print("太郎の点数:", scores["太郎"])
print("花子の点数:", scores["花子"])


# 3. 追加と更新
print("3. 追加と更新")
scores["三郎"] = 85
print("三郎を追加:", scores)
scores["太郎"] = 88
print("太郎を更新:", scores)


# 4. キーがあるか調べる
print("4. キーがあるか")
if "花子" in scores:
    print("花子はあります")
if "四郎" not in scores:
    print("四郎はありません")
```

**実行結果の例**
```
1. 辞書そのもの
{'太郎': 80, '花子': 90, '次郎': 70}
2. キーで取り出す
太郎の点数: 80
花子の点数: 90
3. 追加と更新
三郎を追加: {'太郎': 80, '花子': 90, '次郎': 70, '三郎': 85}
太郎を更新: {'太郎': 88, '花子': 90, '次郎': 70, '三郎': 85}
4. キーがあるか
花子はあります
四郎はありません
```

**ポイント**
- **辞書**は `{キー: 値, キー: 値, ...}` の形です。リストの `[]` ではなく、波かっこ `{}` を使います。
- **取り出し**は `scores["太郎"]` のように、角かっこにキーを書きます。リストの番号の代わりに、キー（ここでは名前の文字列）を使います。
- **追加も更新も**同じ書き方です。まだないキーなら追加、すでにあるキーなら値が書き換わります。
- **`"花子" in scores`** は、キー「花子」があるかどうかを調べます。ないキーで `scores["四郎"]` と書くとエラーになるので、調べてから使うと安心です。
- リストは「順番と番号」、辞書は「名前（キー）で探す」向きです。用途に合わせて使い分けます。

**ミニ課題**

次の辞書があります。

```
ages = {"猫": 3, "犬": 5}
```

これに「うさぎ」を 2 歳として追加し、辞書全体を `print` してください。

ヒント：追加は `辞書[キー] = 値` です。

**答え例**
```python
# 答え
ages = {"猫": 3, "犬": 5}
ages["うさぎ"] = 2
print(ages)
```

実行結果：

```
{'猫': 3, '犬': 5, 'うさぎ': 2}
```

`ages["うさぎ"] = 2` で、新しいキーと値の組が辞書に足されます。表示の順番は環境によって多少違うことがありますが、中身は同じです。
