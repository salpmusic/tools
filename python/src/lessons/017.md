# 第17回：キーワード可変長引数 **kwargs ～名前付きの引数をまとめて受け取る～

**目標**

- **kwargs を使って、名前付きの引数をいくつでも受け取れるようになる。
- **kwargs が辞書（dict）として扱われることを知り、キーと値を取り出せるようになる。
- 普通の引数や前回の *args と組み合わせて、便利な関数を作る。

**BASICとの比較**

前回は、*args を使って、個数が決まっていない引数をまとめて受け取る方法を学びました。

例えば、次のように数をいくつでも渡せました。

```
total(10, 20, 30)
```

今回は、数や文字列を渡すときに、名前も一緒に指定する方法を考えてみましょう。

例えば、人物の情報として「名前」「年齢」「住んでいる町」を関数に渡したいとします。

BASICでは、それぞれの変数を用意したり、配列などに値を入れて管理する方法が考えられます。

BASIC風の疑似コード：

```
10 NAME$="TARO"
20 AGE=25
30 CITY$="TOKYO"
40 PRINT "NAME:";NAME$
50 PRINT "AGE:";AGE
60 PRINT "CITY:";CITY$
```

この方法では、情報の項目が増えるたびに、変数や表示処理を追加する必要があります。

Pythonでは、**kwargs を使うと、名前付きの引数をまとめて受け取れます。

| 比較 | BASIC | Python |
| --- | --- | --- |
| 情報の管理 | 個別の変数や配列など | 辞書（dict） |
| 名前付きの値 | 変数名などで管理 | name="Taro" |
| 複数の情報 | 項目ごとに用意 | **kwargs でまとめる |
| 名前と値の取得 | 個別に参照するなど | items() で取り出す |
| 項目数の確認 | 自分で管理することが多い | len(kwargs) |

例えば、Pythonでは次のように呼び出せます。

```
show_info(name="Taro", age=25, city="Tokyo")
```

このとき、**kwargs は次のような辞書として受け取ります。

```
{"name": "Taro", "age": 25, "city": "Tokyo"}
```

辞書は、キー（名前）と値を組み合わせて保存するデータです。

**kwargs の ** は、複数のキーワード引数をまとめて受け取るための記号です。

kwargs は慣習的な名前で、**info のように別の名前を使うこともできます。

**コード**

```python
# 第17回：キーワード可変長引数 **kwargs
# Python 3.7.3 対応

# 1. 名前付きの引数をまとめて受け取る
def show_info(**kwargs):
    print(kwargs)

print("1. kwargs の基本")
show_info(name="Taro", age=25)
show_info(name="Hanako", city="Tokyo", hobby="Music")


# 2. キーと値を取り出す
def show_profile(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print("\n2. キーと値")
show_profile(name="Mika", age=20, city="Osaka")


# 3. 個数を調べる
def count_info(**kwargs):
    print("情報の個数:", len(kwargs))

print("\n3. 情報の個数")
count_info(name="Taro", age=25, city="Tokyo")
count_info(name="Hanako")
count_info()


# 4. 普通の引数と **kwargs を組み合わせる
def show_card(title, **info):
    print("タイトル:", title)

    for key, value in info.items():
        print(f"{key}: {value}")

print("\n4. 情報カード")
show_card("自己紹介", name="Taro", age=25, city="Tokyo")
show_card("商品情報", name="Apple", price=150)


# 5. 特定のキーの値を取り出す
def show_student(**kwargs):
    name = kwargs.get("name", "名前なし")
    score = kwargs.get("score", 0)

    print(f"{name}さんの点数: {score}点")

print("\n5. 辞書から値を取り出す")
show_student(name="Yuki", score=90)
show_student(name="Ken")
show_student()


# 6. *args と **kwargs を組み合わせる
def show_data(*args, **kwargs):
    print("位置引数:", args)
    print("名前付き引数:", kwargs)

print("\n6. args と kwargs")
show_data(10, 20, name="Taro", city="Tokyo")


# 7. for で情報を一覧表示する
def show_items(**kwargs):
    for key, value in kwargs.items():
        print(f"{key} = {value}")

print("\n7. 商品一覧")
show_items(apple=150, banana=100, orange=120)
```

**ポイント**

- **kwargs は、0個以上のキーワード引数をまとめて受け取る書き方です。
- *args は位置引数をタプルとして受け取り、**kwargs はキーワード引数を辞書として受け取ります。
- 辞書は、{"name": "Taro", "age": 25} のように、キーと値を組み合わせたデータです。
- kwargs.items() を使うと、キーと値をまとめて取り出せます。
- for key, value in kwargs.items(): と書けば、受け取った情報を順番に処理できます。
- len(kwargs) で、受け取った情報の個数を調べられます。
- kwargs.get("name", "名前なし") のように書くと、指定したキーがない場合にも、代わりの値を使えます。
- def show_card(title, **info): のように、普通の引数と組み合わせられます。
- def show_data(*args, **kwargs): のように、*args と **kwargs を両方使うこともできます。この場合は、*args を先に書きます。
- kwargs という名前は自由に変更できますが、一般的には **kwargs と書くことが多いです。
- キーワード引数の名前には、Pythonの識別子として使える名前を指定します。同じ名前を重複して渡すことはできません。
- Python 3.7.3では、辞書のキーは追加された順番を保持します。そのため、通常は渡した順番で表示されます。

**ミニ課題**

### 課題1：ペットの情報を表示しよう

**kwargs を使って、ペットの情報を表示する show_pet() 関数を作ってみましょう。

例えば、次のように呼び出します。

```
show_pet(name="Mike", animal="Cat", age=3)
```

出力例：

```
name: Mike
animal: Cat
age: 3
```

ヒント：for key, value in kwargs.items(): を使います。

### 課題2：商品の価格を合計しよう

**prices を使って、名前付きで渡された商品の価格を合計する total_price() 関数を作ってみましょう。

例えば、次のように呼び出します。

```
total_price(apple=150, banana=100, orange=120)
```

結果は 370円 になります。

ヒント：辞書の値だけを取り出す prices.values() と、合計を求める sum() を組み合わせます。

### 課題3：タイトル付きの情報カードを作ろう

普通の引数 title と、**kwargs を組み合わせて、情報を表示する make_card() 関数を作ってみましょう。

例えば、次のように呼び出します。

```
make_card("旅行メモ", place="Kyoto", days=2, hotel="Sakura")
```

ヒント：最初に title を表示し、そのあと for 文でキーと値を表示します。

**答え例**

```python
# 課題1：ペットの情報
def show_pet(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")


print("課題1")
show_pet(name="Mike", animal="Cat", age=3)


# 課題2：商品の価格の合計
def total_price(**prices):
    total = sum(prices.values())
    print(f"合計: {total}円")


print("\n課題2")
total_price(apple=150, banana=100, orange=120)


# 課題3：タイトル付きの情報カード
def make_card(title, **kwargs):
    print("タイトル:", title)

    for key, value in kwargs.items():
        print(f"{key}: {value}")


print("\n課題3")
make_card("旅行メモ", place="Kyoto", days=2, hotel="Sakura")
```


今回は、**kwargs を使って、名前付きの引数をいくつでも受け取る方法を学びました。

前回の *args は、値をタプルとしてまとめる方法でした。

今回の **kwargs は、名前と値を辞書としてまとめる方法です。

この2つを覚えると、引数の個数や情報の項目が変わっても、同じ関数で柔軟に対応できるようになります。
