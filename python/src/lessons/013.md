# 第13回：関数の定義 ～BASICのGOSUB/RETURNと比べてみよう～

**目標**
- `def` で、まとまった処理に名前を付けて呼び出せるようになる。
- 引数なしと、簡単な引数ありの関数を書けるようになる。
- `return` で計算結果を受け取れることを知る（まずは軽く）。

**BASICとの比較**

BASICでは、同じ処理を何度も使うとき、サブルーチンに飛ばして戻ってきます。

BASICの例：

```
10 GOSUB 100
20 GOSUB 100
30 END
100 PRINT "こんにちは"
110 RETURN
```

`GOSUB` で行番号へ飛び、`RETURN` で元の場所へ戻ります。

Pythonでは、**関数**に名前を付けて、その名前で呼びます。行番号ではなく `def` でまとまりを作ります。

```
def say_hello():
    print("こんにちは")

say_hello()
say_hello()
```

| やりたいこと | BASIC | Python |
|---|---|---|
| まとまりを作る | 行番号のサブルーチン | `def 名前():` |
| 呼び出す | `GOSUB 行番号` | `名前()` |
| 戻る | `RETURN` | 関数の終わり（または `return`） |
| 値を渡す | 変数を共有することが多い | 引数 `def greet(name):` |
| 結果をもらう | 変数に入れることが多い | `return` の値を受け取る |

BASICの `GOSUB` に近い感覚で、「名前を付けた処理を、あとから何度でも呼ぶ」と考えると分かりやすいです。

**コード**
```python
# 第13回：関数の定義

# 1. 引数なしの関数
def say_hello():
    print("こんにちは")
    print("今日もよろしく")


print("1. 引数なし")
say_hello()
say_hello()


# 2. 引数ありの関数
def greet(name):
    print("こんにちは、" + name + "さん")


print("2. 引数あり")
greet("太郎")
greet("花子")


# 3. 戻り値（return）を軽く
def add(a, b):
    return a + b


print("3. 戻り値")
total = add(3, 5)
print("3 + 5 =", total)
print("10 + 20 =", add(10, 20))
```

**実行結果の例**
```
1. 引数なし
こんにちは
今日もよろしく
こんにちは
今日もよろしく
2. 引数あり
こんにちは、太郎さん
こんにちは、花子さん
3. 戻り値
3 + 5 = 8
10 + 20 = 30
```

**ポイント**
- **`def 名前():`** で関数を作ります。中身は字下げ（インデント）します。`if` や `for` と同じ考え方です。
- **`名前()`** と書くと、その関数が実行されます。`def` は「用意する」だけで、呼ばないと動きません。
- **引数**は、呼び出すときに渡す値です。`greet("太郎")` なら、関数の中の `name` に `"太郎"` が入ります。
- **`return`** は、関数から値を返すときに使います。`total = add(3, 5)` のように、結果を変数に入れたり、そのまま `print` したりできます。
- BASICの `GOSUB` は「行へ飛ぶ」、Pythonの関数は「名前で呼ぶ」イメージです。同じ処理を繰り返すときに便利です。

**ミニ課題**

次の関数を作って、2回呼び出してください。

```
def say_bye():
    print("またね")
```

ヒント：`def` のあとに `say_bye()` を2回書けば大丈夫です。

**答え例**
```python
# 答え
def say_bye():
    print("またね")

say_bye()
say_bye()
```

実行結果：

```
またね
またね
```

`def` で用意したあと、`say_bye()` で呼びます。2回書けば、同じあいさつが2回出ます。
