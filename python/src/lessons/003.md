# 第3回：文字列のあつかい（BASICのA$との比較・つなげる・長さ・f-string）

**目標**
- 文字列は「文字が並んだもの」です。
- BASICの `A$` と Python の文字列の違いを知る
- `+` でつなげる・`len()` で長さを調べる・f-string で埋め込む

**BASICとの比較**

BASICでは `A$` のように **$** をつけて区別していましたが、Pythonでは $ は不要です。普通の変数に文字列を入れます。

```
# BASIC: A$ = "こんにちは"
message = "こんにちは"   # Pythonでは $ をつけない
```

つなげる（連結）：BASICでは `A$ + B$` でつなげました。Pythonも同じ `+` です。

```
# BASIC: PRINT A$ + "さん"
name = "太郎"
print(name + "さん")          # → 太郎さん
print("こんにちは、" + name)  # → こんにちは、太郎
```

長さを調べる：BASICの `LEN(A$)` は、Pythonでは `len()` 関数です。

```
# BASIC: PRINT LEN(A$)
text = "Python"
print(len(text))   # → 6
```

f-string（便利な埋め込み）：Python 3.6以降で使える書き方です。文字列の中に `{変数}` を書くだけで、中身を埋め込めます。
BASICの `PRINT "長さは"; LEN(A$); "です"` のようなことを、より読みやすく書けます。

```
name = "花子"
length = len(name)
print(f"こんにちは、{name}さん")          # → こんにちは、花子さん
print(f"{name} の長さは {length} 文字です")  # → 花子 の長さは 2 文字です
```

| やりたいこと | BASIC | Python |
|---|---|---|
| 文字列を入れる | `A$ = "abc"` | `a = "abc"` |
| つなげる | `A$ + B$` | `a + b` |
| 長さを調べる | `LEN(A$)` | `len(a)` |
| 変数を埋め込んで表示 | `PRINT "名前は"; A$` | `print(f"名前は{a}")` |

**コード（そのまま実行できる）**

```python
# 第3回：文字列のあつかい（BASICのA$との比較）
# Python 3.7 で動く文法のみ

print("=== 文字列の基本 ===")
message = "こんにちは"          # BASICの A$ に相当（$ は不要）
print(message)

print("\n=== つなげる（+） ===")
name = "太郎"
print(name + "さん")
print("こんにちは、" + name)

print("\n=== 長さを調べる（len） ===")
text = "Python"
print(len(text))               # → 6

print("\n=== f-string で埋め込み ===")
name2 = "花子"
print(f"こんにちは、{name2}さん")
print(f"{name2} の長さは {len(name2)} 文字です")

print("\n=== 練習問題1の答え ===")
greeting = "おはよう"
name = "花子"
print(greeting + "、" + name + "さん")

print("\n=== 練習問題2の答え ===")
text = "Python入門"
print(f"{text}の長さは{len(text)}文字です")

print("\n=== おまけ：数字を文字列にする ===")
age = 25
print("年齢は" + str(age) + "歳です")     # str() で文字列に変換
print(f"年齢は{age}歳です")               # f-stringなら自動で変換される
```

**実行結果の例**

```

こんにちは

=== つなげる（+） ===
太郎さん
こんにちは、太郎

=== 長さを調べる（len） ===
6

=== f-string で埋め込み ===
こんにちは、花子さん
花子 の長さは 2 文字です

=== 練習問題1の答え ===
おはよう、花子さん

=== 練習問題2の答え ===

=== おまけ：数字を文字列にする ===
年齢は25歳です
年齢は25歳です
```

**ポイント**
- 変数名に $ はつけない（普通の名前でOK）
- 文字列と数字は別物。数字を文字列にしたいときは `str()` を使う
- つなげるときは `+`、長さは `len()`、見やすく埋め込むなら f-string
- この回では `input()` は使わず、あらかじめ値を入れて試しています
- 日本語の文字も `len()` では1文字を1と数えます（`"Python入門"` は8文字）。

**ミニ課題**

問題1：「おはよう」と「花子」を `+` でつなげて、「おはよう、花子さん」と表示してみましょう。

問題2：文字列 `"Python入門"` の長さを調べて、f-stringを使って「Python入門の長さは8文字です」と表示してみましょう。

**答え例**

```python
# 問題1（出力例：おはよう、花子さん）
greeting = "おはよう"
name = "花子"
print(greeting + "、" + name + "さん")

# 問題2（出力例：Python入門の長さは8文字です）
text = "Python入門"
print(f"{text}の長さは{len(text)}文字です")
```
